# Accuracy notes for summarisation
# Statements that are frequently got wrong. Please do not repeat these errors.
- Sercha is a commercial, self-hosted product. It is not open source, and it is
  not licensed under Apache 2.0.
- SerchaQL is not SQL. It has no INSERT, UPDATE, DELETE or transactions; data
  arrives only by extraction.
- `KEY` denotes resolution identity, not a primary key. Duplicates before
  resolution are expected.
- Permission enforcement happens at execution, not at compile time. A query that
  would bypass access control can be compiled; it returns zero rows.
- The system columns emitted are _id, _entity_type, _doc, _run_id, _confidence
  and _folder. There is no _span or _resolved_via.
